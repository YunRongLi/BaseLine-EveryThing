# Agent Thinking Guide

These keys focus on structured thinking that guides agents through systematic problem-solving while resisting common rationalization patterns.

## Agent Thinking Guide Keys:

1. **Explore Project Context** - Understanding the current codebase and requirements before ideation
2. **Ask Clarifying Questions** - One-at-a-time questioning to understand purpose, constraints, and success criteria
3. **Propose Multiple Approaches** - Presenting 2-3 different solutions with trade-offs and recommendations
4. **Present Design Sections** - Breaking down the design into digestible chunks scaled to complexity
5. **Rationalization Prevention** - Explicit language ("NEVER", "ALWAYS") to resist shortcuts and assumptions
6. **Spec Self-Review** - Scanning for placeholders, contradictions, scope issues, and ambiguity
7. **Incremental Validation** - Getting approval at each section before proceeding
8. **Task Checklist Methodology** - Creating ordered tasks to ensure systematic completion
9. **Process Flow Tracking** - Following decision diamonds and state transitions to completion
10. **Anti-Pattern Recognition** - Identifying and blocking common shortcuts (e.g., "this is too simple to need a design")
11. **Visual vs. Textual Decision Making** - Per-question decision about whether to use visual or terminal-based explanations
12. **Scope Decomposition** - Breaking large projects into independent sub-projects when needed
13. **Isolation and Clarity Design** - Ensuring system units have one clear purpose with well-defined interfaces
